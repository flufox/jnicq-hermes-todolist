# Roadmap

## v0.1 — release candidate

- Complete real-device Telegram and Hermes voice-flow validation.
- Close every Critical/High finding and record decisions for Medium findings.
- Run the already validated Compose profiles on a fresh Ubuntu host with Docker and repeat backup/restore there.

## Next

- Guided Google conflict resolution.
- Additional mini-app auth adapters behind the existing interface, after a security review.
- Import/export formats that do not expose integration metadata.
- Extend accessibility and end-to-end mobile regression coverage across more Telegram clients.

## Explicitly not planned for v0.1

SaaS hosting, multitenancy, email login, installing Hermes, multiple application replicas, or a full project-management dashboard.
